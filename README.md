## 🌟 Tentang Proyek

**KITA MENIKAH** dikembangkan secara mandiri (*independent solo project*) sebagai solusi inovatif atas permasalahan katalog vendor pernikahan konvensional yang kaku dan membosankan. 

Platform ini menghadirkan pengalaman berbelanja dan kurasi vendor layaknya menjelajahi aplikasi smartphone premium:
- **Zero Framework Bloat:** Dibangun dengan performa tinggi menggunakan arsitektur Single Page Application (SPA) murni tanpa beban dependensi berlebih.
- **Micro-Interactions Kelas Dunia:** Dilengkapi suara haptic bell romantis, Dynamic Island interaktif, dan status bar jam real-time.
- **Editorial Design Language:** Menggabungkan tipografi serif klasik (*Cormorant Garamond*) dan kebersihan font modern (*Plus Jakarta Sans*).

## ✨ Fitur Unggulan

### 1. 📱 Simulator Hardware iPhone 16 Pro Max
- Bingkai fisik Titanium Hitam presisi ultra-HD dengan speaker slit, action button, dan tombol volume.
- Homescreen interaktif iOS dengan smart widget cuaca, jam digital otomatis, dan *bubble app launcher* beranimasi halus.

### 2. 🎬 Vertical Video Reels Engine (TikTok-Style)
- Navigasi usap vertikal (*swipe gesture*) untuk portofolio video asli (MP4) perias manten, venue adat, prosesi akad, dan busana.
- Dilengkapi sistem interaksi instan: tombol Love, Bookmark, Share, Sound wave indicator, serta tombol langsung menuju profil vendor terkait.

### 3. 👰 Interactive Bridal Checklist & Budget Planner
- Manajemen persiapan pengantin H-124 menuju hari bahagia.
- 8 fase vendor esensial dengan progress bar dinamis dan status centang otomatis.
- Estimator anggaran transparan bersistem Rekber Aman (DP 20%).

### 4. 🔄 Dual Operating Modes (Klien & Vendor)
- **Mode Klien:** Eksplorasi katalog 8 kategori, pencarian cepat, filter gaya riasan/dekorasi, dan simulasi paket harga.
- **Mode Mitra Vendor:** Dashboard internal untuk mengelola rincian pesanan masuk, penghitungan komisi platform, dan rekap pendapatan bersih (*Net Earnings*).

## 🚀 Cara Menjalankan Secara Lokal

Bagi pengembang atau calon pemilik yang ingin menjalankan preview di jaringan lokal:

```bash
# 1. Clone repositori
git clone https://github.com/juansvmmerdose/kita-menika.git

# 2. Masuk ke direktori
cd kita-menika

# 3. Jalankan server lokal
python serve.py

# 4. Akses melalui browser
http://localhost:8080  # di komputer
http://192.168.x.x:8080 # di smartphone (jaringan WiFi yang sama)
```
